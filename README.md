# Summary

Paddy’s website is open-source, simple, and fully transparent. You can suggest changes, study how it works, use it as a reference, fork it, or build your own version.

Beyond being a simple website:
- can be installed as an app using supported browsers
- stores HTML-based Twitch widgets
- includes an unused Garry’s Mod HUD experiment
- and other junk
